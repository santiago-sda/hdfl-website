## Accepted Scope — Implementation Spec

### 1. Working Filter Pills (`components/projects/ProjectFilter.tsx`)

**Pattern:** Extract `ProjectFilter` as a client component. Keep `app/projects/page.tsx` as a server component that passes the `projects` array as a prop.

```tsx
// components/projects/ProjectFilter.tsx
'use client'; // Required: uses useState and renders motion.div via ProjectCard
```

**Filtering logic:**
- `useState<string>('All')` for active category
- Filter: `project.category === activeCategory` (exact string match). `"All"` shows every card.
- `project.category` values in `lib/data.ts` (`"HCD"`, `"AI Engineering"`, `"BI & Dashboards"`, `"Capstone"`) match the pill labels exactly. **Note:** `capabilityTracks[3].name` is `"Graduate Capstone"` — a different string that must never be used for filtering. Add an inline comment in `lib/data.ts` flagging this intentional divergence.
- **Animation:** Use `AnimatePresence` with per-card `layout` prop on `ProjectCard`'s root `motion.article` — this animates cards in/out individually without full DOM remount. Do NOT use `key={activeCategory}` on `StaggerContainer` (causes full remount flicker on every filter click). Confirm `ProjectCard.tsx` passes `variants={staggerItem}` from `AnimatedSection.tsx`; if not, add it.
- Empty-state guard: if no projects match, render `<p className="col-span-full text-center text-text-muted py-12">No projects in this category yet.</p>`

### 2. New `/team` Page (replaces redirect)

export interface TeamMember {
  id: string;

  role: "director" | "coach";

export const teamMembers: TeamMember[] = [
  // USER MUST SUPPLY: 2 directors (role: "director") — name, title, bio, avatar URL
  // USER MUST SUPPLY: 10 coaches (role: "coach") — name, title, avatar URL
  // Use i.pravatar.cc/150?u={name} as avatar placeholder until real headshots provided

**Page layout (`app/team/page.tsx`):**
- Replace `redirect("/tracks")` with a real server component page
- `PageHero` with label "Our Team", title "Directors & Coaches"
- Directors section: 2-column card grid (`grid grid-cols-1 sm:grid-cols-2`), name + title + bio
- Coaches section: `grid grid-cols-2 sm:grid-cols-3 lg:grid-cols-4`, name + title + avatar only
- CTA at bottom linking to `/contact`

**Navbar — `lib/data.ts`:** Insert `{ href: '/team', label: 'Team' }` **after** `{ href: '/about', label: 'About' }`. Keep the existing `{ href: '/tracks', label: 'Tracks' }` entry — it serves a different purpose (capability track details, not team bios). Adding to `navLinks` automatically propagates to Footer quick links via `Footer.tsx:43–52`.
